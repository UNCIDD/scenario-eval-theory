# scenario-eval-theory

The code in this repository can be used to reproduce analysis from 

**Assessing model error in counterfactual worlds** \
Howerton and Lessler, *Journal of the Royal Society Interface* (2026) \
DOI: [10.1098/rsif.2025.1176](https://doi.org/10.1098/rsif.2025.1176})

## File structure and definitions
* `\R` contains all scripts to perform analyses and generate figures
  * `\simulation`
    * `\0_final-size-functions.R` functions to simulation model projections of final epidemic size
    * `\0_helper-functions.R` functions to process simulation results and implement analysis components
    * `\0_parameters.R` script to set parameters for primary simulation experiment
    * `\1_generate_simluations.R` script to run primary simulation experiment
    * `\2_impelement_error_estimation_approaches.R` script to impelement Approaches 1-3 for estimating model errors under counterfactual scenarios
    * `\3_evaluate_performance.R` script to compare estimated model errors to true model errors
  * `\figures` contains all scripts to generate main text and supplemental figures
* `\output` contains all figures and simulation output files
  * `\figures` contains `.pdf` files of all main text and supplemental figures, including primary versions generated by scripts in the `R\figures\` folder, as well as final versions onto which additional annotations have been added via Adobe Illustrator (*_AI.pdf)
  * `\output` includes all simulation output files
